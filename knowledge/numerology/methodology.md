# Numerologia — metodologia v1

## Sistema
Numerologia ocidental de matriz pitagórica.

## Fonte metodológica de referência
Numology — Our numerology methodology:
https://numology.io/methodology

A fonte descreve um método pitagórico de 3 ciclos para cálculos de data de nascimento e preservação de 11/22/33 em determinadas etapas.

## Regra de produto
Não chamar uma metodologia específica de “a verdadeira numerologia”. Há escolas diferentes.

## Redução
Uma função de redução deve ser parametrizada:
- reduzir números compostos
- preservar 11, 22, 33 quando a regra do cálculo exigir
- registrar a metodologia usada.

## Caminho de vida / número de destino
Para o método de 3 ciclos:
1. reduzir mês conforme regra;
2. reduzir dia conforme regra, preservando mestre quando aplicável;
3. reduzir ano;
4. somar os resultados;
5. reduzir o resultado final conforme regra, preservando mestre.

## Nome
Para cálculos baseados em nome, criar tabela explícita de letras → números e normalização de acentos.
Não apagar acentos de forma inconsistente.

## Dados
Cada resultado deve guardar:
- method
- method_version
- input_hash
- calculated_at

## Linguagem
Usar “na numerologia, este número é associado a...”.
Não apresentar como diagnóstico científico.
