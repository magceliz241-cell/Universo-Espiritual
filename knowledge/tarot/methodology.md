# Tarot — metodologia v1

## Tradição
Rider-Waite-Smith como referência principal.

## Estrutura
78 cartas:
- 22 Arcanos Maiores
- 56 Arcanos Menores.

## Arcanos Maiores
A sequência pode ser lida como uma narrativa simbólica conhecida como jornada do Louco, mas não existe obrigação de usar uma única interpretação.

## Arcanos Menores
4 naipes:
- Paus
- Copas
- Espadas
- Ouros

Cada naipe:
Ás, 2–10, Pajem, Cavaleiro, Rainha, Rei.

## Orientação
- upright: leitura direta.
- reversed: leitura invertida/modificada.

Reversa não precisa significar “oposto”; pode representar bloqueio, excesso, internalização, atraso ou expressão distorcida.

## Sorteio
O software escolhe as cartas.
A IA nunca deve inventar a carta sorteada.

## Interpretação
A carta é um símbolo. A leitura deve considerar:
- pergunta
- posição da carta
- orientação
- cartas vizinhas
- contexto do usuário.

## Segurança editorial
Não usar Tarot para diagnosticar doenças, determinar culpa, afirmar morte, garantir eventos futuros ou substituir orientação profissional.
