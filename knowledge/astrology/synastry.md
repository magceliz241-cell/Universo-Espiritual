# Sinastria / mapa do casal

## Objetivo
Comparar dois mapas para identificar contatos simbólicos entre planetas e ângulos.

## Dados
Para cada pessoa:
- data
- hora
- local
- posições planetárias
- casas
- ASC/MC se a hora for conhecida.

## Contatos relevantes
- Sol–Lua
- Sol–Vênus
- Sol–Marte
- Lua–Vênus
- Lua–Marte
- Mercúrio–Mercúrio
- Mercúrio–Vênus
- Mercúrio–Marte
- Vênus–Marte
- Saturno com luminares/Vênus/Marte
- Júpiter com planetas pessoais
- contatos com ASC/Desc/MC/IC
- sobreposição de planetas nas casas do outro.

## Regra de interpretação
Não gerar “compatibilidade 92%” como se fosse medida científica. Produzir dimensões:
- afinidades
- facilidades
- diferenças
- pontos de tensão
- comunicação
- afeto
- desejo
- limites
- crescimento
- perguntas para reflexão.

A IA recebe os aspectos já calculados.
