# Aspectos

Aspecto é a distância angular entre dois pontos do mapa. A interpretação depende de:
- planetas envolvidos
- signos
- casas
- orbe
- aplicante/separativo quando a metodologia usar
- dignidades/contexto

No MVP, usar os cinco aspectos maiores.
Orbes devem ser configuráveis e versionados; não “inventar” um orbe único para todos os casos.
